1. Proprietary Lightway Protocol: Unrivaled Speed & Efficiency

For many years, the VPN industry relied almost exclusively on legacy protocol implementations such as OpenVPN and IKEv2. While secure, OpenVPN contains over 70,000 lines of complex legacy code, resulting in noticeable connection delays, high battery drain on mobile phones, and frequent dropouts when switching between Wi-Fi and mobile data networks.

To eliminate these fundamental bottlenecks, ExpressVPN engineered Lightway completely from scratch in the efficient C programming language with less than 2,000 lines of codebase. This radical minimalism provides three transformative advantages:

  • Sub-Second Connection Times: Lightway establishes an encrypted tunnel virtually instantaneously—frequently in less than 200 milliseconds—so you never have to wait for your VPN to connect.
  • Superior Mobile Battery Efficiency: By avoiding bloated cryptographic handshakes, Lightway reduces processor overhead, conserving significant smartphone and tablet battery life during active sessions.
  • Seamless Network Roaming: When your device transitions from a home Wi-Fi network to mobile 5G, Lightway maintains the encrypted session in a dormant state and restores the tunnel instantaneously without dropping packets or leaking your true IP address.
  • Open-Source & Independently Audited: The core Lightway engine is completely open-source and has undergone exhaustive third-party code security audits by Cure53 to verify cryptographic resilience.
memory Figure 2: TrustedServer Volatile RAM Architecture & Zero Hard Drive Storage 18+ Independent Audits

2. TrustedServer Technology: Total RAM-Only Security

Traditional servers rely on physical hard disk drives (HDDs) or solid-state drives (SSDs) to store operating system files, server configurations, and system logs. In conventional setups, data remains physically written to disks until explicitly overwritten, introducing substantial risk if physical hardware is seized or compromised.

ExpressVPN solved this foundational vulnerability by developing TrustedServer technology across its entire fleet of servers in 105 countries. Key innovations include:

  1. Pure Volatile RAM Execution: ExpressVPN servers run exclusively in volatile random-access memory (RAM). Because RAM requires continuous electrical power to preserve data, every byte of operational state is instantaneously wiped the moment a server is rebooted or powered down.
  2. Cryptographic OS Stack Re-Installation: On every single startup, the entire server operating system is freshly loaded from a secure read-only image signed cryptographically by ExpressVPN engineers. This prevents configuration drift, malware persistence, and rogue software alterations.
  3. Audited by World-Leading Firms: ExpressVPN’s no-logs infrastructure and TrustedServer mechanisms have been independently verified through comprehensive public audit reports conducted by PricewaterhouseCoopers (PwC), KPMG, and Cure53.
